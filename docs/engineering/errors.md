# Errors

Nothing in slackmap, isa-users or isa-tools is urgent, isa-users' sign-up included: if something is down, people tell us, and being down for a while is fine. Email alarms were read by nobody. So each project's errors land once a week as GitHub issues labelled `errors:{project}`, where an agent can pick them up and fix them when asked; an error surfaces up to a week late, by design.
