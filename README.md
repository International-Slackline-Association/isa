# ISA

Monorepo of the [International Slackline Association](https://www.slacklineinternational.org/).

| Folder | What it is |
|---|---|
| [aws-platform](aws-platform/docs/README.md) | The ISA's AWS organization: accounts, access, guardrails, shared resources (CDK) |
| [isa-tools](isa-tools/docs/README.md) | Tools API, certificate verification and the listing pages embedded on the ISA website |
| [isa-users](isa-users/docs/README.md) | ISA accounts: the user pool ISA apps sign in with, the account web app and its API |
| [slackmap](slackmap/docs/README.md) | The world slackline map at slackmap.com, its API and map data |
| [docs](docs/README.md) | Repo-wide docs: why one monorepo, how software is built here, and the documentation system |

Start at [docs/README.md](docs/README.md).
