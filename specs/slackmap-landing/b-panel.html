B, refined: the map panel

The sidebar becomes a panel with two tabs, Activity and Communities, both following the part of the map you're looking at. No Explore tab. Selecting a line, spot or guide shows its card in the same panel; "‹ Back" returns to the tab. The first set of options is in wireframes.html.

Desktop

Phone

The panel becomes a bottom sheet with three heights: peek (one line), half, full. The map stays in charge; the sheet is pulled up only by people who want more.

How hard is "latest in view"?

Small. Every change is already indexed per country (GET /country/:code/changelogs exists), and the browser already knows which countries are on screen and where every feature is (each feature in the map file carries its country and position).

Communities works the same way: the existing GET /communities/country/:code returns the members and groups per country, and the groups' map file already has their positions for "3 in view".
