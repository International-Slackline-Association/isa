# Documentation system

> Important Reminder! This repo is transitioning to this documentation system. Things are not there yet. Always keep in mind.

The rules for how this monorepo documents itself. Every session already holds the [agent essential knowledge](agent-essential-knowledge.md). Anyone touching a doc reads all of this, in this order.

1. [The theory of this system](the-theory.md): everything else follows from it; read once
2. [Content rules](content-rules.md): what goes into a doc and what stays out, skills and agent instructions included
3. [Folder convention](folder-convention.md): where a doc lives, what a README holds, how docs link
4. [Frontmatter spec](frontmatter-spec.md): the fields, the six types, what makes a doc findable
5. [Reading docs](reading-docs.md): how you find what you need during a task, and what to do when the docs are missing, legacy or wrong
6. [Updating docs](updating-docs.md): how a change starts and the steps for each type, ending in the review; skeletons in [templates](templates.md)
7. [Adversarial review](adversarial-review.md): how a review runs: the one-sentence call, existence before mechanics, the code opened for every document, the pen, what comes back
8. [Agent skills](agent-skills.md) and their [rules](agent-skill-rules.md): before writing a skill, command, agent brief or hook, or deciding where one lives
9. [Notes](notes.md): what is open in the system itself

Background, kept as a deliberate exception to the content rules: [relation to other approaches](relation-to-other-approaches.md).
