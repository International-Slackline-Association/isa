# Communities

The groups used to live in the slackline-data repository and changed only through a Google Form or a pull request that ISA merged by hand; submissions waited for months. Making a group a slackmap feature, edited in the app like a line or spot, makes that repository obsolete.

- **The slackmap ISA account owns every group, and no line, spot or guide.** It holds the rights a creator has on every group, so ISA can operate the data in the web app.
- **ISA membership is set only by that account**, and a group ISA recognizes is edited by ISA only, its earlier editors removed: ISA-recognized groups are official ISA data.
- **Contact data stays public as people entered it**, personal emails and phone links included: people shared it willingly.
- **Abuse is a later worry.** Anyone signed in can edit a group; nothing guards against vandalism today, and a bad edit is recovered from a backup by hand.
