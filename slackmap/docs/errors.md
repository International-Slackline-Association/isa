# Errors

Nothing in slackmap is urgent: if something is down, people tell us, and being down for a while is fine. Email alarms were read by nobody. So errors land once a week as GitHub issues labelled `errors:slackmap`, where an agent can pick them up and fix them when asked; an error surfaces up to a week late, by design.
